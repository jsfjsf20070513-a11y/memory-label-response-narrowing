# 证据与解释边界

## 1. 本轮真正观察到什么

文献层面的观察：

- 身份、画像和记忆信息会改变语言模型输出，这一点已有多条研究路线支持。
- 有些记忆系统会过度使用无关信息，表现为重复、谄媚、偏好主导或遗漏一般建议。
- 真实用户并不总认为个性化回答优于通用回答。
- LLM 判官可能高估个性化，也可能偏爱自身或相似模型的输出。
- 相关性门控、可不用记忆、通用核心答案和多视角补充是有根据的干预方向。

项目层面的冻结观察：

- 当前证据只来自冻结模型、题目、通道和背景注入方式。
- 在该范围内，数学背景条件更容易出现“数学组织焦点增加、非数学路径减少”。

## 2. 不能直接推出什么

现有证据不能证明：

- 模型内部存在某种已经被识别的“记忆收窄机制”；
- 数学本科生标签在其他模型、题目或通道中普遍造成同样变化；
- “更数学”对数学本科生天然更差；
- 自动语义距离等于单回答内的实质路径数量；
- 三名盲判一致就等于构念本身完全有效；
- 一句“背景不是指令”就足以解决无关记忆干扰。

## 3. 最接近的证据为什么仍不等价

| 研究线 | 它回答了什么 | 仍缺什么 |
|---|---|---|
| MyScholarQA | 真人用户会认为部分个性化行动建议过窄 | 不是单纯身份标签实验，也没有直接计算最终回答少了多少路径 |
| MirrorStories | 身份个性化文本可由对应用户评价，且可能更受欢迎 | 多样性是整批故事层面的，不是单篇回答角度覆盖 |
| Re-Centering Humans | 个性化不自动优于通用回答，LLM 判官会高估 | 评价者不是原画像用户，且没有测单回答收窄 |
| OP-Bench / RPEval | 记忆会产生过度个性化或过滤气泡 | 用户和数据大量合成，价值判断主要依赖自动判官 |
| DRIFTLENS | 可测记忆注入后的理由轨迹变化 | “路线不同”不等于“路线变少”，外显理由也不是隐藏机制 |
| The Basic B*** Effect | 个性化代理可能压缩个人跨主题选择范围 | 是替用户做选择，不是生成开放回答 |

## 4. 新颖性口径

允许写：

> 在截至 2026 年 7 月 29 日的注册检索范围内，我们尚未发现一项研究同时操纵身份标签有无、测量单条开放回答的实质内容路径收窄，并由相应用户评价其实际价值。

不允许写：

- “没人做过”；
- “本项目首次证明个性化导致回答变窄”；
- “数学背景会让模型回答变差”。

## 5. 下一步证据优先级

1. 新判官做开放编码，检查现有二元规则是否真的对应更一般的内容收窄。
2. 由数学本科生和适当对照用户判断帮助、遗漏、过度假定和是否希望启用背景。
3. 复现多种等义背景措辞和注入位置。
4. 比较直接注入、资料边界、注入前相关性门控、通用核心答案加可选个性化补充。
5. 同时报 `M-N`、`N-G` 和 `M-G`，因为三者回答不同问题。

更详细的逐篇方法、结果和局限见 [`../review.md`](../review.md)。

## 6. 当前核验记录的缺口

- 最终综述中的具体数字来自本轮全文阅读，但当前包没有为每条数字保存节号、表号或页码。因此它是便于快速理解的综合报告，还不是可以逐条追溯的正式论断账本；若用于论文写作，应先补齐“论断—原文位置—证据摘记”的对应表。
- `metadata_verified` 只说明书目元数据已核，不等于全文中的每项论断都完成【原文核】。
- 本轮没有保存每个数据库的完整结果页、每条查询的命中数和逐条排除轨迹，因此不能包装成 PRISMA 级系统综述。
- 检索以英文 CS/NLP 来源为主；中文检索未发现直接证据，不等于中文数据库中必然不存在相关研究。
- 2026 年预印本可能继续改版，后续引用时需要重新核对版本。
- 当前三名人类盲判的关账状态是 `calibration_supported`，它不是独立复制，也不是完全双盲。
