# 文献检索协议

检索日期：2026-07-29  
项目基线：`e6f8275032f53b774fa95ceae42a23a3f005bbcd`

## 1. 研究问题

本轮优先检查：

> 2024-01 至 2026-07，是否已有研究系统检验“身份或背景标签使开放回答的实质内容路径变少，而这种变化对相应用户究竟是帮助还是限制”？

候选论文按五项条件判断：

1. **A-i 背景对照**：比较注入身份/背景与未注入条件。
2. **A-ii 收窄测量**：直接测回答覆盖的角度、方向或方面是否减少；只测内容改变、准确率或情感极性不算。
3. **A-iii 用户价值**：评价质量、有用性、满意度或遗漏。
4. **A-iv 目标用户**：评价者是相应用户，或有充分依据的用户代理。
5. **A-v 开放生成**：任务产生开放回答，而不是分类、事实问答或推荐排序。

`5/5` 才算抢先，`4/5` 算近似抢先，`≤3/5` 只算相关工作。最终综述未检出 `4/5` 或 `5/5` 的已核候选；这不是对全部学术文献的穷尽性证明。

## 2. 适用范围

- 核心前沿窗口：2024-01 至 2026-07。
- 个性化、记忆与多样性方法：向前追溯到 2021/2022。
- 人类评价和测量理论：为寻找方法基础，最早追溯到 2018。
- 语言：英语为主，补充中文查询。
- 学科：NLP、HCI、个性化系统、长期记忆、过滤气泡、多样性测量和生成评价。

## 3. 检索来源

本轮使用或核验的来源包括：

- ACL Anthology；
- arXiv；
- OpenReview；
- PMLR；
- NeurIPS Proceedings；
- OpenAlex；
- Semantic Scholar；
- Crossref；
- PubMed Central / Europe PMC；
- 出版商或期刊官方页面；
- ACM/CHI 相关页面与引文追踪。

不同来源承担不同功能：广泛召回、预印本发现、正式书目核对、引用追踪、全文核验和开放许可确认不能互相替代。

## 4. 纳入标准

满足以下至少一项：

- 直接研究身份、画像、Persona 或记忆如何改变语言模型回答；
- 直接研究过度个性化、过滤气泡、内容/选择收窄或群体同质化；
- 提供语义多样性、观点覆盖或长度控制的可借用量具；
- 检验真实用户对个性化回答的价值判断；
- 检验 LLM 判官、人类一致性或评价构念有效性；
- 提供相关性门控、记忆筛选、输入边界或多视角生成干预。

## 5. 排除或降级规则

- 只因标题含 `personalization`，但不能缩小本项目下一步问题的文献，不进入核心综述。
- 只测“回答不同”，不测“回答路径变少”的论文不能算收窄研究。
- 只用 LLM 判官的价值判断不能替代目标用户评价。
- 摘要不足以支持方法、样本或具体数字时，不把相关说法升级为正文级证据。
- 无法由官方来源唯一定位的名称不独立计数；方法名、数据集名和论文名会合并去重。
- 预印本与同行评审论文分开标记。

## 6. 去重规则

依次使用：

1. DOI；
2. arXiv ID；
3. 其他官方来源 ID；
4. 标题、年份和首位作者。

`MyScholarQA`、`RPEval`、`Self-ReCheck`、`RP-Reasoner`、`MetricEval`、`PerSE` 和 `LUFY` 等名称均合并到对应论文，不重复计算。

## 7. 核验等级

- **全文核**：打开正文，核对方法、结果或局限；具体数字只能来自这一层。
- **元数据核**：核对官方页面、题名、作者、年份、venue、DOI/arXiv 和摘要。
- **检索线索**：只用于继续追踪，不能写进实质结论。
- **无法核验**：明确登记原因，不猜测。

本包的 `papers.json` 表示书目和许可元数据已核，不表示 51 篇全部都做了同等深度的全文精读。最终综述逐篇标明“全文核”或“摘要核”。

## 8. PDF 与许可规则

1. 有公开 PDF 链接不等于允许第三方重新托管。
2. 只有论文页面、出版商政策或 OA 仓储明确给出可分享许可时，才将 PDF 纳入仓库。
3. arXiv 默认 non-exclusive distribution license 只授权 arXiv 分发，本项目按“不足以重新托管”处理。
4. 所有纳入 PDF 均保持原样，不裁剪、不批注、不移除版权页。
5. 每份文件登记来源、许可、大小和 SHA-256。

## 9. 停止规则与限制

检索在以下条件满足后停止扩展：

- 五要素候选、评价方法和干预方法三条主线均出现重复命中；
- 新查询主要返回已去重条目或明显低相关结果；
- 核心候选完成全文或官方摘要核验；
- 已形成可以改变下一步实验设计的证据，而不是继续为增加篇数而搜索。

限制：

- 这不是正式 PRISMA 系统综述；本轮没有保存每个数据库每条查询的逐级命中数。
- 中文数据库覆盖和索引可得性有限。
- 某些付费或反机器人页面只能核验摘要/元数据。
- 2026 年的新论文引用数尚不稳定，不能用低引用简单判定质量。
- “未检出”只对本协议的日期、来源和查询有效。
