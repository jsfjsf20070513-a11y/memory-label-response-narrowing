# 第三方论文 PDF

本目录保存 43 份经许可核验、未经修改的论文 PDF。

- 完整书目信息：[`../metadata/papers.json`](../metadata/papers.json)
- 每份文件的来源、许可、大小和 SHA-256：[`../metadata/download_manifest.json`](../metadata/download_manifest.json)
- 许可分组与特殊限制：[`LICENSES.md`](LICENSES.md)

这里没有收录另外 8 篇官方可读但再分发许可未确认的 PDF。它们的官方页面和跳过原因仍在 manifest 中。

不要删除论文版权页，不要把本目录理解为对论文重新许可，也不要把项目自身的许可套到这些第三方文件上。
