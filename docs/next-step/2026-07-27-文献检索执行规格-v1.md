## 0. 目的与非目的

**目的**:为 Issue #5 的拍板提供材料。产出一份**"在本轮规定的检索范围内未检出已有答案的问题清单"**,外加抢先权判定。

**措辞纪律(lingyun 第二轮复核要求):全程不得写"没人做过""没人知道"。** 检索只能证伪新颖性(找到一篇即可),不能证实新颖性;任何"未检出"都必须同时写明**检索范围**:年代窗口、检索源、查询串。想把结论说得更强,唯一的办法是扩大范围并如实登记,不是换个说法。

**非目的**:不是写 related work,不是凑参考文献数量,不是证明我们的方向正确。

判断一条文献要不要记录,只看一件事:**它有没有帮我们缩小"下一步该问什么"的范围。** 帮不上就不记,少而准优于多而虚。

## 1. 核验档位(写死,全单通用)

每条文献必须标且只标一档:

| 档位 | 含义 |
|---|---|
| **【原文核】** | 打开了摘要页或正文,逐字确认题名 + 作者 + 年份 + venue;所转述的发现或数字在文中定位到了具体位置。 |
| **【元数据核】** | 打开了页面,确认存在且元数据无误,但发现只来自摘要。 |
| **【仅检索命中】** | 只在搜索结果里见过,未打开页面。**不得进入正文表格**,只能进"待核清单"。 |
| **【无法核验】** | 打不开 / 搜不到 / 元数据对不上。写明原因。 |

**硬规则:**

1. 正文只允许【原文核】和【元数据核】。
2. **凡引用具体数字,必须【原文核】,并注明数字在文中的位置**(节号 / 表号)。
3. **模型给出的题名、作者、年份、数字,必须由执行的人本人打开原页面看过,才能标核过。** 模型此刻是生成者,不是核验者。

**为什么这么严:** 本项目 2026-07-06 的第一轮文献清扫由单一模型自动流水线产出,经异族二审发现 **22 个来源中 13 个题名是流水线自造的、2 组数字挂错了论文**,另有 2 条至今出处失联被永久禁引。抓出这批错的正是 Codex——同一个模型,换到核验位置就能抓错,留在生成位置就会犯错。位置决定可靠性,不是牌子。

## 3. 第一轮任务(勘察,四项)

### 任务 1 · 七篇精读

对 §2 全部 7 篇,每篇只记四项,每项一到三句,**不要摘要复述**:

1. 研究问题是什么;
2. 用什么方法测的;
3. **哪一点我们能直接借用**(量具、设计、控制变量);
4. **它和我们的差别在哪**——这一项最重要,写不出差别说明没读懂。

### 任务 2 · 抢先权检查(针对 Issue #5 候选 A 提议的新问题)

**问题**:2024-01 至 2026-07,是否已有工作系统研究过 **"身份/背景标签导致的回答窄化,对用户究竟是好是坏"**?

**五要素**(按 lingyun 第二轮复核加严。原四要素漏掉了两件事,会把"个性化改变了回答内容"这类不相干研究误判成抢先):

- **A-i** 比较了"注入身份标签"与"未注入"两种条件下的回答;
- **A-ii** ⭐ **确实测量了"回答窄化"本身** —— 即回答覆盖的角度 / 方向 / 方面在数量或分布上减少。
  **不算数的**:只测内容改变、偏好一致度、谄媚率、刻板印象褒贬、情感极性、准确率;
- **A-iii** 因变量含**质量 / 有用性 / 满意度**的判断,即回答了"这样是好是坏";
- **A-iv** ⭐ 评价者是**目标用户或有依据的用户代理**(例如声称"对数学系学生有益"就该由数学系学生评)。
  **不算数的**:纯 LLM-as-judge;与主张人群无关的通用众包判官——他们只能回答一般感知质量;
- **A-v** 任务是开放式生成,不是事实问答、分类或推荐排序。

判定:**5/5 = 抢先**;**4/5 = 近似抢先**,写明缺哪条;**≤3/5 = 归入相关工作**,不算抢先。

**A-ii 与 A-iv 是这次新加的,也是最容易被漏判的两条。** 报每一条候选时都要逐要素写明判定,不得只给总分。

**成功标准是"找到",不是"确认没有"。** 一条都没找到时,必须附完整检索词表(≥12 个查询串,跨 ≥3 个检索源)以证明真的找过。

### 任务 3 · 方法学:AI 判官在价值判断上靠不靠谱

Issue #5 候选 A 提出的核心预测是"**AI 尺子能量结构,量不了价值**"。查三件事:

1. **AI 判官与人类在"哪个回答更好"上的一致性典型量级是多少?** §2 第 3 篇已给一个负面结论,还有没有别的?
2. **人类判官之间**在"哪个回答更好"上一致性有多高?——**这条最关键**。如果人和人本来就对不上,这个实验根本测不出东西(见 Issue #5 候选 A §六第 2 处)。
3. 当人类判官被要求使用与 AI **完全相同的结构化编码规则**时,一致性会不会被结构本身抬高?若文献里有对应术语(circularity / criterion contamination / shared-method variance 之类),**把术语找出来比找到论文本身更有用**。

**待挑战的不利先验(转述,未核):**

## 5. 检索特有的两条红线

仓内 `AGENTS.md` 与 `DATA_BOUNDARIES.md` 全部有效,此外:

1. **检索词零 PII**。姓名、学号、邮箱、学校名一概不入查询串。"数学系本科生"这类匿名角色描述可以用。
2. **不编造。打不开就写"无法核验 + 原因",不许凭训练记忆填补。** 2025—2026 的 preprint 大概率不在任何模型的训练数据里,必须实际联网打开。若执行环境无联网检索能力,**立刻停止并报告**,不得在离线状态下产出任何判定。

本单不碰不可逆资源:只读网页 + 写一个文件。**不含任何开跑授权**,不得启动模型采样或产生新实验数据。
