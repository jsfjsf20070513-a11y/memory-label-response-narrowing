# 文献检索执行规格 v1

> 2026-07-27。配套讨论稿见 [`2026-07-27-下一步讨论稿.md`](2026-07-27-下一步讨论稿.md)。
> **谁执行都一样。** 人、Codex、Claude 按同一份规格,不因执行者是模型还是人而放宽。
> 红线以仓内 `AGENTS.md` 与 `DATA_BOUNDARIES.md` 为准,本文件不重写红线,只补检索特有的两条(见 §5)。

## 0. 目的与非目的

**目的**:为讨论稿的拍板提供材料。产出一份**"目前没人知道答案的问题清单"**,外加抢先权判定。

**非目的**:不是写 related work,不是凑参考文献数量,不是证明我们的方向正确。

判断一条文献要不要记录,只看一件事:**它有没有帮我们缩小"下一步该问什么"的范围。** 帮不上就不记,少而准优于多而虚。

## 1. 核验档位(写死,全单通用)

每条文献必须标且只标一档:

| 档位 | 含义 |
|---|---|
| **【原文核】** | 打开了摘要页或正文,逐字确认题名 + 作者 + 年份 + venue;所转述的发现或数字在文中定位到了具体位置。 |
| **【元数据核】** | 打开了页面,确认存在且元数据无误,但发现只来自摘要。 |
| **【仅检索命中】** | 只在搜索结果里见过,未打开页面。**不得进入正文表格**,只能进"待核清单"。 |
| **【无法核验】** | 打不开 / 搜不到 / 元数据对不上。写明原因。 |

**硬规则:**

1. 正文只允许【原文核】和【元数据核】。
2. **凡引用具体数字,必须【原文核】,并注明数字在文中的位置**(节号 / 表号)。
3. **模型给出的题名、作者、年份、数字,必须由执行的人本人打开原页面看过,才能标核过。** 模型此刻是生成者,不是核验者。

**为什么这么严:** 本项目 2026-07-06 的第一轮文献清扫由单一模型自动流水线产出,经异族二审发现 **22 个来源中 13 个题名是流水线自造的、2 组数字挂错了论文**,另有 2 条至今出处失联被永久禁引。抓出这批错的正是 Codex——同一个模型,换到核验位置就能抓错,留在生成位置就会犯错。位置决定可靠性,不是牌子。

## 3. 第一轮任务(勘察,四项)

### 任务 1 · 七篇精读

对 §2 全部 7 篇,每篇只记四项,每项一到三句,**不要摘要复述**:

1. 研究问题是什么;
2. 用什么方法测的;
3. **哪一点我们能直接借用**(量具、设计、控制变量);
4. **它和我们的差别在哪**——这一项最重要,写不出差别说明没读懂。

### 任务 2 · 抢先权检查(针对讨论稿提议的新问题)

**问题**:2024-01 至 2026-07,是否已有工作系统研究过 **"身份/背景标签导致的回答窄化,对用户究竟是好是坏"**?

四要素:

- **A-i** 比较了"注入身份标签"与"未注入"两种条件下的回答;
- **A-ii** 因变量含**质量 / 有用性 / 用户满意度**的判断(不只是准确率,也不只是多样性计数);
- **A-iii** 有**真人评价**参与(不是纯 LLM-as-judge);
- **A-iv** 任务是开放式生成,不是事实问答或推荐排序。

判定:4/4 = 抢先;3/4 = 近似抢先,写明缺哪条;≤2/4 = 归入相关工作。

**成功标准是"找到",不是"确认没有"。** 一条都没找到时,必须附完整检索词表(≥12 个查询串,跨 ≥3 个检索源)以证明真的找过。

### 任务 3 · 方法学:AI 判官在价值判断上靠不靠谱

讨论稿提出的核心预测是"**AI 尺子能量结构,量不了价值**"。查三件事:

1. **AI 判官与人类在"哪个回答更好"上的一致性典型量级是多少?** §2 第 3 篇已给一个负面结论,还有没有别的?
2. **人类判官之间**在"哪个回答更好"上一致性有多高?——**这条最关键**。如果人和人本来就对不上,这个实验根本测不出东西(这正是讨论稿 §六留给 lingyun 打的第 2 处)。
3. 当人类判官被要求使用与 AI **完全相同的结构化编码规则**时,一致性会不会被结构本身抬高?若文献里有对应术语(circularity / criterion contamination / shared-method variance 之类),**把术语找出来比找到论文本身更有用**。

### 任务 4 · 旧线不利先验的接续

`LITERATURE.md`(旧线,已经过 Codex 异族二审)缺口 B 记录:Hines et al. 2024 *Spotlighting*(arXiv:2403.14720)测过精确的读法前言,结论是**前言单独几乎无效**;MemSyco 的 memory-caution 干预净效果因系统而异。

查:**2024 年之后有没有推翻这个不利先验的工作?** 若有,Codex 提的"相关性门控 / 用户开关"方向就重新有戏,讨论稿 §四的第 4 条理由作废。

## 4. 输出

产出单一文件,建议路径 `paper/reading-notes/2026-07-27-literature-scan.md`,或贴进本 PR 的讨论区。结构:

1. **执行环境声明(放最前)**:哪些检索是人做的、哪些是模型辅助的、用了哪个模型、用了哪些检索源、执行日期、**是否有任何正文条目是在执行者本人没打开过页面的情况下写的**(应为"无")。
2. 任务 1:7 篇 × 四项。
3. 任务 2:抢先/近似抢先清单(四要素逐条判定)+ 检索词表。
4. 任务 3:三问各自的答案 + 检索词表。
5. 任务 4:结论(推翻 / 未推翻)+ 检索词表。
6. **待核清单**:所有【仅检索命中】,注明为何没打开。
7. **一句话交付**:读完之后,"目前没人知道答案的问题"有哪几个?按你的判断排序。

第 7 项是本单真正的产出,前六项都是它的证据。

## 5. 检索特有的两条红线

仓内 `AGENTS.md` 与 `DATA_BOUNDARIES.md` 全部有效,此外:

1. **检索词零 PII**。姓名、学号、邮箱、学校名一概不入查询串。"数学系本科生"这类匿名角色描述可以用。
2. **不编造。打不开就写"无法核验 + 原因",不许凭训练记忆填补。** 2025—2026 的 preprint 大概率不在任何模型的训练数据里,必须实际联网打开。若执行环境无联网检索能力,**立刻停止并报告**,不得在离线状态下产出任何判定。

本单不碰不可逆资源:只读网页 + 写一个文件。**不含任何开跑授权**,不得启动模型采样或产生新实验数据。

## 6. 分工建议

- **§2 第 3 篇两个人都读**,各自独立写"它对我们的方法意味着什么",写完再对答案。那篇是唯一直接威胁本项目测量体系的,分开读会导致只有一个人看见威胁。
- 其余 6 篇可分,任务 2 / 3 / 4 可分。
- **任务 2 开始之前,两个人各自先写下"我猜答案是哪边"并存档**,查完再对照。这样能知道自己有没有被文献带跑。
