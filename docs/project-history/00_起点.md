# 第一步：回答是否变窄

> 日期：2026-07-10  
> 状态：只确定了研究对象；没有冻结判据，没有设计完试跑，没有开跑授权。

## 现在真正要问的话

> 面对同一个本来可以从很多角度回答的问题，知道"用户是数学系学生"的模型，是否更容易集中在数学相关角度，同时减少其他方向？

## 已经分开的三件事

1. **身份显形**：回答直接说"你是数学系学生".
2. **数学取向**：回答虽未必提身份，但把主要注意力放在数学角度.
3. **回答变窄**：数学取向增强的同时，原本可以出现的其他有意义方向变少.

三者不得再互相代替.

## 下一步

在看任何新结果之前，先把下面两句话说清楚：

1. 一个人只看两份回答时，凭什么判断哪份"看到的角度更少"?
2. 怎样的开放问题真的允许多个方向，又不会在题目里偷偷暗示数学?

两句没说清楚前，不定样本量，不写统计检验，不开跑.
