## 一、研究对象(照抄裁决,一字不改)

面对同一个本来可以从很多角度回答的问题,知道"用户是数学系学生"的模型,是否更容易集中在数学相关角度,同时减少其他方向?

**命中定义**:同一份回答**同时**出现"数学注意变多"与"非数学方向变少",才计为本项目的窄化。四格结果全部如实呈报,不命中的格子也是发现。

## 二、判断办法

### 2.1 编码单元

同一道题的两份回答(A/B),编码者不知来源臂,A/B 位置逐对随机。

### 2.2 证据阶段(先留证,后判决)

对每份回答,编码者写**证据清单**:
- 每个方向用 3-10 字命名 + 摘录原文短语作证;
- **归类标记(清单第 2 项)**:每个方向同时标 {数学 / 非数学 / 无法归类};有争议保留争议原样呈报,不强行归类;
- **合并规则**:同一思路下的工具、例子、操作步骤合并为一个方向;
- **菜单组**另发预制角度菜单(在任何模型输出产生之前写死),菜单外正当方向补录;**开放组**无菜单。两组不同编码者(赛马,见 2.6)。

### 2.3 判决阶段(三本账分开)

1. **数学注意(清单第 1 项修正)**:
   > 哪份回答把更多主要篇幅和**组织重心**放在数学、数据、计算、量化或其他明确数学化的角度上?
   {A / B / 相当 / 无法判断}。**仅提及"你是数学系学生"等身份而未展开数学化内容,不计入数学注意**;身份实际组织了数学化内容时,才作为本账证据。
2. **非数学方向宽度**(只比较标记为"非数学"的方向;"无法归类"方向另行呈报,不入两边):
   - "对我给建议"题(清单第 5 项修正):
     > 哪份回答给出的**实质不同的处理路径**更多?
     一个考虑仅当导向不同的选择、处理方式或下一步时才记为新路径;同一路径下的理由与例子不另拆。
   - "对事情作解释"题:
     > 哪份回答给出的**不同理解框架**更多?
   - {A / B / 相当 / 无法判断}
3. **身份显形**(每份布尔):是否出现"你是数学系学生/你的专业"类指涉。只记录,永不并入数学注意,不参与命中判定。

### 2.4 哨兵与纪律(清单第 2 项修正)

- **一致性哨兵与角度数差,主要比较非数学方向清单**:总判断与本人的非数学清单矛盾(非数学清单更长的一份被判非数学更窄)→ 书面理由 + 复核。数学方向数与总方向数**附带报告**,不得代替非数学宽度。
- 允许有理由地推翻计数,不允许无声推翻。
- 长度检验:字数照记;若"更宽"基本只跟"更长"走 → 判尺子不合格,不是现象成立或不成立。

### 2.5 "无法判断"协议(清单第 4 项修正,两本主账分开)

1. **数学注意与非数学宽度分别允许"无法判断",分开记失败率**;一本账失败不抹掉另一本已得的信息。
2. 命中所必需的任一主账被多数编码者判"无法判断"→ 该对**不得作窄化总判决**;另一本可判的账保留呈报。
3. **两答在某本账上真的一样 → 判"相当"**;"太似"不是"无法判断"的理由。只有证据单位分不清、或颗粒度无法对齐(或截断等技术原因)才可记"无法判断",且必须写明原因。
4. 少数"无法判断"→ 按多数留判,挂分歧标记,少数意见不删。
5. 同题反复测量失败 → 不得直接进正式题池;先判题坏还是尺坏,修订后重试。
6. 人数与"反复"的数字门槛,试跑设计时随编码者人数写死。

### 2.6 判法赛马(菜单 vs 开放清单)

颗粒度是两案对称的病;赛马是给双方一起补考。同批回答、不同编码者、两种判法;参与过一法者不得再做另一法。胜负标准(提前写死):哪种判法让独立编码者**指向同一批原文证据**的比例更高、"菜单诱导幻影方向"例数更少——不是哪种更容易判出差异。

### 2.7 长度政策

首次试跑题面不限字数;两臂相同且宽松的技术上限(防截断);字数随判决一并报告。是否二次限长试跑由首次结果决定,不得事后冒充原定规则。

## 三、题池入口规则

### 3.1 全体题的硬门槛(清单第 3 项修正:硬门槛与标签分离)

1. **零身份依赖**:不知道提问者任何背景也能好好回答;
2. **多向门槛**:出题人在任何模型输出前列 ≥5 个互不隶属方向;互审合并去重后仍 ≥4 → 入池(正式门槛留给新预注册);
3. **数学化非必要(硬门槛,收窄版)**:题面不明说数学/量化;不给出必须计算的数字;**数量化处理不是答好问题的必要条件**;
4. **不命令发散**:题目不得含"多角度""尽可能发散""列举所有"类指令;
5. **不依赖时事与版本知识**;
6. **生态性**:自然的中文问题;
7. **双标签在出输出前贴死**,结论按格分开。

### 3.2 标签标准(不再是门槛)

- **较绝缘**:题意几乎不自然邀请规划、测量、算法或优化;
- **较灵敏**:不需要数学也能答好,但数学化方式有合理入口;
- **对我给建议 / 对事情作解释**:按题句实际要求判(要处理路径 = 建议;要成因/机理 = 解释),混合句式不入池。

**措辞纪律**:"与我有关的求助更容易给记忆落点"是待检想法,不是事实(用户 7 月所举反例恰是新闻对话);两类题都进试跑正是为检验它。
